# Prism — Data Insights Studio

Interactive browser-based CSV analytics and reporting workspace built as a portfolio project by Alper Sancar.

## Capabilities
- Upload and parse real CSV files locally in the browser
- Handles quoted CSV fields and escaped quotes
- Automatic numeric-column detection
- Dataset row/column profiling
- Dynamic category filters
- Numeric distribution visualization
- Minimum, maximum, mean, median and sum calculations
- Automatic factual findings based on the current filtered dataset
- Data preview table
- Responsive analytics workspace
- Demo dataset included for immediate exploration

## Privacy
Uploaded CSV data is processed in the browser. This portfolio version does not upload datasets to a server.

## Stack
HTML5, CSS3, Vanilla JavaScript, FileReader API, custom CSV parser, client-side statistics and visualization.

## Scope
This project demonstrates front-end data processing and exploratory analytics. The generated findings are deterministic calculations from the loaded dataset; they are not presented as AI-generated business predictions.
